# Heart-Disease-Prediction-using-Machine-Learning-
This project focuses on building a robust Machine Learning pipeline to predict the likelihood of heart disease in patients based on clinical parameters. By leveraging classification algorithms, the model identifies patterns in medical data (such as cholesterol levels, blood pressure, and age) to assist in early diagnosis.

📊 Dataset
The project utilizes a heart disease dataset (e.g., the UCI Heart Disease Dataset) containing several clinical features:

Age, Sex, Chest Pain Type (CP)

Resting Blood Pressure (trestbps)

Cholesterol (chol)

Fasting Blood Sugar (fbs)

Maximum Heart Rate Achieved (thalach)

Target: (0 = No Heart Disease, 1 = Heart Disease)

🛠️ Tech Stack
Language: Python

Libraries: * Data Analysis: Pandas, NumPy

Visualization: Matplotlib, Seaborn

Machine Learning: Scikit-learn

Database (Optional): SQLite (for storing patient records)

🚀 Workflow
Exploratory Data Analysis (EDA): Analyzing feature correlations and distributions using heatmaps and histograms.

Data Preprocessing: Handling missing values, feature scaling (StandardScaler), and encoding categorical variables.

Model Selection: Training and comparing multiple classifiers:

Logistic Regression

Random Forest Classifier

Support Vector Machine (SVM)

K-Nearest Neighbors (KNN)

Evaluation: Assessing performance using Accuracy, Precision, Recall, and F1-Score.
